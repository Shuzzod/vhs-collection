VHS Коллекция

Веб-приложение для учёта коллекции VHS-кассет. Работает в браузере, не требует регистрации и установки. Сделано для русскоязычных коллекционеров: учитывает студии релиза, локализации и состояние кассет, которых нет в зарубежных аналогах.

Что умеет

- Добавлять кассеты: название, студия, локализация, год, состояние, фото обложки.
- Выбирать студию и локализацию из списка или вводить своё — новое значение запоминается.
- Искать по коллекции и фильтровать по студии и локализации.
- Сортировать по названию, году или дате добавления.
- Редактировать и удалять кассеты.
- Сохранять коллекцию в JSON-файл и загружать обратно.

Как пользоваться

1. Откройте сайт: `https://shuzzod.github.io/vhs-collection/`
2. Заполните форму и нажмите «Добавить кассету». Фото обложки сжимается автоматически.
3. Чтобы изменить кассету — нажмите «Редактировать» в её карточке.
4. Чтобы найти нужное — используйте поиск и фильтры над коллекцией.

Важно: где хранятся данные

Коллекция хранится в браузере на вашем устройстве (localStorage). Это значит:

- Данные не синхронизируются между телефоном и компьютером.
- При очистке кэша браузера или удалении данных сайта коллекция пропадёт.
- Другой человек на том же сайте не увидит вашу коллекцию.

Поэтому скачивайте JSON после каждого добавления партии кассет. Кнопка «Скачать коллекцию (JSON)» — ваша страховка. Файл можно загрузить обратно через «Загрузить коллекцию» на этом же или другом устройстве.

Как перенести коллекцию на другое устройство

1. На старом устройстве нажмите «Скачать коллекцию (JSON)» — сохранится файл `vhs-collection.json`.
2. Передайте файл на новое устройство (почта, мессенджер, флешка).
3. На новом устройстве откройте сайт и нажмите «Загрузить коллекцию», выберите файл.
4. Кассеты появятся в коллекции.

Ограничения текущей версии

- Нет аккаунтов и синхронизации между устройствами.
- Нет распознавания кассет по фото — обложку нужно загружать вручную.
- Нет автозаполнения из внешних баз (TMDB и т.п.).
- Фото хранятся в сжатом виде (~30–60 КБ), чтобы влезать в лимит браузера. При очень большой коллекции (сотни кассет с фото) хранилище может закончиться.
